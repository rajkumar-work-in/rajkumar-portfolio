about

From structured data work to structured code.

I hold a B.Sc in Mathematics from Thiruvalluvar University and spent close to two years working as a Data Entry Operator, where I got comfortable with accuracy, structured information, and process discipline. Alongside that role, I trained as a Java Full Stack Developer and moved my focus toward software engineering.

My work today centers on Java and Spring Boot on the backend, and React on the frontend — building applications with a clear separation between the presentation layer, business logic, and persistence. I care about writing code that stays understandable after the first draft.

Outside of project work, I spend time on data structures and algorithms and reading about system design, because I'd rather understand the trade-offs behind a decision than just apply a pattern. I'm still early in this career, and I treat that as a starting point worth being upfront about, not something to talk around.

how-i-build

How I build.

The same six-step pass I run through on every project, small or large.

01

Understand

Understand requirements, constraints, and who the application is actually for.

02

Design

Define components, API contracts, and data models before writing implementation code.

03

Implement

Build the frontend and backend incrementally, keeping each layer independently testable.

04

Test

Test APIs, edge cases, and application behavior — not just the happy path.

05

Deploy

Containerize where useful and deploy to a real environment, not just localhost.

06

Improve

Monitor, debug, and refactor based on what actually breaks or gets slow.
